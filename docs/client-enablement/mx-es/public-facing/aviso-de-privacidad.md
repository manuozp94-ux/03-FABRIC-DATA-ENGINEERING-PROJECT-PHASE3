## 2. Datos personales que se pueden recabar

Dependiendo de la forma de contacto o interaccion con este sitio, se podran recabar los siguientes datos personales:

- nombre
- correo electronico
- nombre de empresa u organizacion
- cargo o rol profesional
- informacion incluida voluntariamente en mensajes, formularios o solicitudes
- datos tecnicos basicos de navegacion, cuando correspondan al funcionamiento del sitio

En principio, este sitio no esta diseñado para solicitar datos personales sensibles. Se solicita no enviar datos sensibles salvo que exista una necesidad expresa y una base valida para su tratamiento.

## 3. Finalidades del tratamiento

Los datos personales recabados podran ser tratados para las siguientes finalidades primarias:

- responder solicitudes de contacto
- atender preguntas sobre servicios, proyectos o colaboraciones
- dar seguimiento a conversaciones profesionales o comerciales
- evaluar posibles proyectos, propuestas o relaciones de trabajo
- mantener comunicacion relacionada con el servicio solicitado

De manera secundaria, y solo en caso de que aplique y sea procedente, los datos podran utilizarse para:

- mejorar la claridad del sitio y la experiencia de contacto
- llevar control interno de prospectos, oportunidades o seguimiento comercial

Si no desea que sus datos se utilicen para finalidades secundarias, podra solicitarlo mediante los medios de contacto indicados en este aviso.

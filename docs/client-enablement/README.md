# Client Enablement

This folder contains the reusable client-engagement and legal-enablement layer for future consulting or contractor work.

It is intentionally separate from the current Phase 1 analytical MVP. The current portfolio case study remains the primary product. This folder supports how future client work can be scoped, documented, and delivered.

## Structure

- `shared/`: reusable discovery, delivery, and correspondence templates
- `mx-es/`: Mexico-oriented documentation in Spanish
- `us-en/`: U.S.-oriented documentation in English

## Usage Rule

Treat these files as working templates and process assets. Do not represent them as final legal advice without qualified review.

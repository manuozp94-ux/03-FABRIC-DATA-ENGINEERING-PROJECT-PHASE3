# Distilled Notes

This folder is for short, reusable notes derived from official sources in `../source-registry.md`.

## Note Rules

- Write in our own words.
- Link back to the exact official source.
- Capture the learning value, not a full copy of the original page.
- Include the verification date so we know when to refresh.

## Suggested Naming

- `dp-700-study-guide.md`
- `fabric-fundamentals-map.md`
- `lakehouse-and-ingestion-path.md`
- `security-and-governance-baseline.md`

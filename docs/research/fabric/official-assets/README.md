# Official Assets

This folder is reserved for direct-download assets published by Microsoft, such as:

- official PDFs
- certification posters
- lab guides
- downloadable workbooks

## What Does Not Belong Here

- saved copies of arbitrary Microsoft Learn HTML pages
- browser print-to-PDF exports created locally without an official downloadable source
- third-party summaries or community copies

## Intake Rule

Only add an asset here when the original Microsoft source exposes the file directly.

When you add one, also record:

- source URL
- fetched date
- official title
- why the asset matters

## Suggested Naming

`YYYY-MM-DD--microsoft--short-title.ext`

Examples:

- `2026-03-25--microsoft--dp-700-study-guide.pdf`
- `2026-03-25--microsoft--fabric-certification-poster.pdf`

# Scope Register

last_updated: 2026-09-05

## Active Scope

### MVP V2

The active MVP is a bounded operating-loop decision-support proof:

`demand pressure -> decision queues -> purchase orders, movements, fulfillment -> inventory effects -> Gold dashboard outputs -> Power BI and public-site explanation`

### In Scope

- deterministic, public-safe Bronze input package
- live Fabric Lakehouse proof with Bronze, Silver, Gold, runtime governance, and financial foundation outputs
- operating-loop tables for recommendations, purchase orders, movements, fulfillment, and inventory posture
- semantic model and measure pack for three dashboard views
- Power BI request-access surface supported by safe screenshots
- Astro public site that explains the business case, technical method, current proof status, and request-access path
- public-safe repo evidence across the three existing phase-specific repos
- interview-ready walkthrough and defense pack

### Out Of Scope For Current MVP

- ERP replacement claims
- real-time operational control tower claims
- optimization engine claims
- anonymous Publish to web distribution
- raw invoice-source finance claims
- real geography or identity-revealing business labels
- custom CRM/contact database as Phase 1 behavior
- new dashboard subjects before Sales, Supply Chain, and Inventory views are complete
- strict event-sourced inventory accounting as a completed claim

### Current Dashboard Views

- Sales Dashboard
- Supply Chain Decision Support
- Inventory Decision Support

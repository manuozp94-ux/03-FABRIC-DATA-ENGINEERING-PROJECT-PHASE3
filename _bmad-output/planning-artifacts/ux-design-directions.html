UX Design Directions

Six visual directions for the public case-study experience, all aligned to the same trust-first, progressive-proof strategy.

01. Editorial Proof 02. Systems Ledger 03. Calm Proof 04. Warm Intelligence 05. Technical Archive 06. Structured Narrative
Recommended lead: Direction 03
Best for: mixed audiences, long-form proof, bounded technical credibility
Blend option: 03 base + 01 headline style + 05 evidence panels

Design Direction Showcase

These directions all preserve the same product logic: business tension first, analytical clarification second, technical credibility third. What changes is the visual weight, rhythm, and framing.

Use this file to compare tone, density, navigation feel, and how much “editorial” versus “technical” energy the site should project.
